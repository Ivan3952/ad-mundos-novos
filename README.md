# Ad mundos novos — галактика

Интерактивная карта планет участников ивента «Ad mundos novos».
Чистый HTML + Canvas, без сборки на сайте; хостится на GitHub Pages.

## Структура
- `source/` — оригиналы работ (не трогаются скриптом, заодно бэкап)
- `data/works.json` — список работ: файл, название, автор, описание, ссылка, группа
- `img/`, `planets.js` — **генерируются**, руками не править
- `data/overrides.json` — ручные правки поверх импорта
- `tools/import_bot.py` — импорт из бота; `tools/build.py` — сборка; `tools/inspect_db.py` — просмотр схемы базы

## Обновить из базы бота (основной способ)
Из корня репозитория, бот может работать — база открывается только на чтение:
```
python tools/import_bot.py "Z:\Личное\SW\art_event_bot\event.sqlite3"
python tools/build.py
git add -A && git commit -m "Обновление галактики" && git push
```
- Импорт берёт все работы ивента `ad_mundos`: автор, ссылка на пост, полный текст,
  ссылка на статью (melcherry и т.п.), все картинки. Первая картинка — планета на карте,
  остальные — галерея в карточке.
- Название ищется в тексте («Название: …» или короткая первая строка). Где его нет,
  импорт пишет предупреждение.
- Ручные правки — в `data/overrides.json` по id работы в боте: `name`, `description`,
  `hidden`, `featured` (победители → к ядру), `cover` (номер картинки-обложки), `group`, `x`, `y`, `size`.
  Они переживают повторный импорт.

## Добавить работы вручную
1. Положить картинки в `source/`.
2. Дописать их в `data/works.json` (формат — в начале `tools/build.py`).
3. `pip install pillow` (один раз), затем из корня репозитория:
   `python tools/build.py`
4. Закоммитить и запушить — Pages обновится сам.

## Как работает раскладка
- `group` — рукав галактики (день/тема). Есть 2+ группы → по рукаву на группу,
  иначе общая «подсолнуховая» спираль.
- `featured: true` — ближе к ядру (победители).
- Размер и разброс считаются от id детерминированно: новая работа не перемешивает старые.
  Другой вариант раскладки: `--seed 2`. Ручные `x`/`y` в works.json имеют приоритет.
- Пересечения расталкиваются автоматически.
- Тёмный фон картинки становится прозрачным (режим screen); светлый фон скрипт
  определяет сам и приглушает.
