# Ad mundos novos — галактика

Интерактивная карта планет участников ивента «Ad mundos novos».
Чистый HTML + Canvas, без сборки и зависимостей; хостится на GitHub Pages.

## Как добавить планету
1. Подготовить картинку (уменьшение + мягкое затемнение краёв в чёрное):
   `python tools/prepare.py исходник.jpg img/p06.jpg`
   Для работ не на чёрном фоне добавить силу маски: `... img/p06.jpg 1.0`
2. Добавить запись в `planets.js`: id, img, x, y, size, name, author, link, description.

Чёрный цвет на карте становится прозрачным (режим наложения screen), поэтому вырезать планеты не нужно.
Ссылка на конкретную планету: `.../#p03`.

## Публикация
Settings → Pages → Deploy from a branch → `main` / `(root)`.
